# Подпивковичи 🍻

Самостоятельное приложение для общения с навигацией в стиле Discord. React + TypeScript, Node.js 24, SQLite и LiveKit. Интерфейс на русском, для компьютера и телефона.

## Возможности

- Текстовые каналы: история, WebSocket, реакции, редактирование, удаление, закрепления, поиск, эмодзи и вложения до 8 МБ.
- Друзья: заявки с подтверждением, статусы, личные сообщения, история и счётчики непрочитанного. Переписка обновляется каждые 2,5 секунды.
- Голосовые комнаты до 10 участников, камера, выбор устройств, индивидуальная громкость и отключение входящего звука.
- Видео и экран из Signal: исходное разрешение, 1080p/1440p, 30/60 fps, H.264/VP9/VP8, профили текста и движения, настраиваемый битрейт и звук вкладки при поддержке браузером.
- Обработка микрофона из Coherent: фильтр 85 Гц, AudioWorklet, мягкий порог, подавление щелчков, компрессор, лимитер, уровень микрофона, управление подавлением эха и шума. Настройки сохраняются в браузере.
- Приглашения и модерация каналов: владелец, администраторы, исключение, блокировка и отключение публикации медиа.

## Разработка

Нужен Node.js 24+. Установите зависимости через `npm ci --ignore-scripts`, запустите проверки `npm test`, соберите интерфейс `npm run build` и запустите `npm start`. Для разработки интерфейса доступен `npm run dev`.

Настройки среды задаются отдельно: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `APP_ORIGIN`, а для медиа — `LIVEKIT_URL`, `LIVEKIT_PUBLIC_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`. Секреты и действующие конфигурации не входят в репозиторий. В production обязательны HTTPS и WSS. Каталог `deploy` содержит шаблоны изолированной установки и обновления из GitHub; адрес передаётся при установке. Изменения в служебных скриптах требуют отдельной проверки перед применением.

## Ограничения

Это самостоятельная реализация основных сценариев, без совместимости с Discord. Пока нет иерархии нескольких серверов, матрицы пользовательских ролей, веток обсуждения, ботов, звонков в личных сообщениях и мобильного приложения. Канал объединяет текстовую беседу и связанную голосовую комнату. Поддержка захвата звука экрана зависит от браузера и выбранного источника. Нагрузочная проверка десяти реальных участников должна выполняться отдельно.
